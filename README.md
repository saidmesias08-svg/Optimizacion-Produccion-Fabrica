Programa en C para calcular tiempos y recursos de producción en una fábrica de componentes electrónicos.

# Optimización de Producción en una Fábrica de Componentes Electrónicos

## Descripción
Este proyecto consiste en desarrollar un programa en lenguaje C que permite gestionar los productos de una fábrica de componentes electrónicos y calcular los recursos y el tiempo necesarios para cumplir con la producción solicitada.

## Funcionalidades
- Registrar hasta 5 productos.
- Mostrar los productos registrados.
- Buscar productos por su nombre.
- Editar la información de los productos.
- Eliminar productos registrados.
- Calcular el tiempo total de fabricación.
- Calcular los recursos necesarios.
- Verificar si la fábrica puede cumplir con la producción según el tiempo y los recursos disponibles.

## Tecnologías utilizadas
- Lenguaje de programación C.
- Arreglos.
- Funciones.
- Ciclos y estructuras condicionales.
- Punteros.

## Restricciones
- No se utilizan estructuras (`struct`).
- No se utilizan archivos para almacenar datos.
- La búsqueda de productos se realiza mediante lógica propia.
